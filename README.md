## Требования
Python: 3.13.15

Зависимости указаны в requirements.txt.

## Локальный запуск

1. Открыть терминал в папке `wine_app`.

2. Создать виртуальное окружение:
```commandline
   python3 -m venv .venv 
```

3. Активировать окружение:
```commandline
    source .venv/bin/activate
```

4. Установить зависимости:
```commandline
    python -m pip install -r requirements.txt
```

5. Запустить приложение:
```commandline
    python -m streamlit run app.py
```

## Ответы на вопросы:
`st.cache_resource` применяется для загрузки обученной модели, чтобы повторно использовать один объект. А `st.cache_data` применяется для загрузки test.csv и
сохранения вероятностей на тестовой выборке.

Без кэширования модель повторно загружалась бы с диска при каждом действии пользователя, замедляя приложение.
